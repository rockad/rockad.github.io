Purpose & Scope

Personal Workspace App is a single-user local command-line and MCP (Model Context Protocol) utility. It is used exclusively by its owner, samrockad@gmail.com. There are no other users, no registration, and no public or hosted instance of this tool. This policy describes how it handles Google user data.

Google API Data Accessed

The tool requests only the following Google API scopes:

  • openid, userinfo.email, userinfo.profile - basic Google account identity for single-user authentication.
  • gmail.readonly, gmail.compose, gmail.send, gmail.modify, gmail.labels, gmail.settings.basic - reading, drafting, sending, labeling, and managing the owner's Gmail messages and settings when requested by the owner.
  • calendar.readonly, calendar, calendar.events - reading and managing the owner's Google Calendar events and availability.
  • documents - reading and editing Google Docs documents specified by the owner.
  • drive.file - per-file Drive access to list, create, and manage Google Docs created or opened by this tool.

No other Google APIs, data types, or accounts are accessed outside the owner's own workflows.

Data Storage & Sharing

All OAuth credentials, tokens, and any fetched mail or calendar data remain strictly local on the owner's own workstation. The tool runs locally and communicates only with Google's APIs.

  • No external or third-party servers are operated or used by this tool.
  • No analytics, telemetry, tracking, or advertising is present.
  • No Google user data is shared, transferred, sold, or disclosed to any third party.

Limited Use compliance. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data Deletion & Revocation

The owner can revoke this tool's access to their Google Account at any time from the Google Account Permissions page: https://myaccount.google.com/permissions. Locally stored token files can be deleted from the workstation at any time; once deleted, the tool no longer has access to any Google data.

Changes to This Policy

Any future change to the scopes or data handling described above will be reflected on this page together with a revised effective date.
